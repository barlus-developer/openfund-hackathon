# Decisions

- Solidity 0.8.30 / Prague, OpenZeppelin 5.6.1, Foundry 1.7.1; vendored forge-std 1.17.0. Optimizer 200 runs with IR compilation. Runtime core size is below EIP-170's limit. Future public chains must support the configured EVM version or explicitly rebuild with a compatible target.
- React 19, Vite 8, TypeScript 6 strict, React Router 7, Wagmi 3, Viem 2 and TanStack Query 5. Compatible MetaMask Connect EVM 2 uses the current official Wagmi connector. A single connector handles extension/mobile; no parallel fake login or duplicate injected wallet. npm lockfile pins actual resolutions.
- Vercel React guidance and shadcn Base UI components are used. There is no Next.js runtime. shadcn's unused theme package was removed. jsdom 29 supports the available Node patch. uuid is overridden to patched 11.1.1; SDK usage is API-compatible v4/validation and the build/tests are checked.
- Fund IDs and global proposal IDs start at 1. Version names uniquely map to a chain/address and must not be reused across chains. Hash routes preserve static/IPFS deep links.
- Initial approvers do not automatically vote. Sensitive action timelock includes closure and recipient updates. All windows use exclusive upper boundaries. Approval after quorum is unnecessary and rejected.
- Continuous underfunding policy must be enum-zero REFUND as a neutral encoding; contradictory inputs revert. Continuous funds never accumulate refundable donor storage. Targeted REFUND contributions remain stored after successful funding but never become eligible.
- Initial allowlist is capped at 100 to bound creation gas. An empty allowlist is valid; governance must add recipients before spending. Subsequent recipient changes use one address per proposal.
- On-chain identity title, summary and category are immutable; manager updates only presentation URI/hash. UTF-8 byte limits accommodate Lao explicitly. Location is descriptive and included in immutable terms hash. Wizard terms hash: `keccak256(UTF8(terms + "\nLocation: " + location))`.
- Evidence and report digests are keccak256 of **exact raw content bytes**, not the CID text. Reports may use proposal ID 0 for general updates or an executed same-fund payout ID. Reports may be added to closed archives; financial actions remain terminal.
- CLOSING permits necessary recovery and recipient changes for settlement under normal governance. Zero balance implies no executable positive financial obligation because proposals do not reserve money; final close invalidates proposals without iterating history.
- No protocol fee, automated redemption, UI mint, arbitrary rescue, fiat service or application backend. Seed supply is CLI-only, restricted to loopback Anvil 31337.
- The npm Foundry 1.7.1 wrapper does not forward native process exit codes. `scripts/foundry.mjs` invokes the platform binary directly, forwards signals and propagates failures. Dependencies are resolved from the lockfile; no global Foundry installation is required.

- Remote developer networks use an explicit, receipt-verified manifest import with compiled runtime checks and protected-registration validation. Network/testnet metadata, native gas currency and confirmation depth are independent of the DEMO OFL label. The selected default version comes from `VITE_DEFAULT_DEPLOYMENT`; browser RPC overrides are scoped to that version’s chain. Existing version identities cannot be repointed by the importer. Local redeployment preserves remote demo records.
- Shared settings live in the ignored root `.env`, read by Vite (`envDir`) and Node development helpers. Only public `VITE_` variables enter the SPA. CLI-only RPC credentials, keystores and Pinata JWTs are not bundled. Browser RPC URLs are explicitly public configuration.
- Real IPFS uploads support authenticated HTTPS Kubo proxies, preserving endpoint prefixes, and Pinata public signed uploads. A one-shot CLI issues five-minute, 5 MB upload capabilities; no signing backend is added. Authorization/signed URLs are held only in the mounted upload component and cleared after each attempt. Actual service CIDs are used; pinning availability remains external.
